# LISUNGI — Vue d’ensemble produit

## Éditeur

**Lisungi Hub** — startup éditrice du logiciel.  
Ce n’est pas une ONG.

## Produit

**LISUNGI** — solution de gestion humanitaire et organisationnelle.

## Première organisation utilisatrice

**Alliance des Femmes pour le Développement — AFD ASBL**  
Domaine : `afd-rdc.org`

## Modules existants (instance AFD)

- Tableau de bord & analytics
- Opérations (programmes, projets, activités, urgences, stocks, logistique)
- Suivi & impact (bénéficiaires, indicateurs, enquêtes)
- Communication (actualités, médiathèque, newsletter)
- Engagement (messages, adhésions, dons, opportunités)
- RH & paie
- Finances
- Rapports, documents, import intelligent (OCR)
- Administration (utilisateurs, sécurité, journal)

## Modules futurs (produit)

- Sélecteur multi-organisations
- Portail abonnement / facturation Lisungi Hub
- LISUNGI Desktop (sync hors-ligne)
- LISUNGI Mobile (agents terrain)
- Marketplace de modules
