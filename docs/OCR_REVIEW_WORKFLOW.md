# Workflow de révision

1. Import → file OCR  
2. Extraction → `needs_review` ou `inconsistent`  
3. Révision deux panneaux (`/revision`)  
4. Soumission validation  
5. Approbation (finance : pas d’auto-approbation par l’importateur)  
6. Plan d’application → confirmation → apply  
7. Rollback logique possible  

Champs critiques à faible confiance : révision obligatoire.
