# Sidebar réduite — UX

## Dimensions

- Largeur réduite : **80px**
- Icônes principales : **24px** (`size-6`)
- Zone cliquable : **48px** (`h-12`)
- Mode ouvert : icônes **18px**

## Comportement

Clic sur une icône de groupe en mode réduit :
1. ouvre la sidebar ;
2. ouvre le groupe sélectionné ;
3. affiche les libellés.

Distribution verticale : `justify-evenly` + `gap` adaptatif.
Bouton **Voir le site public** ancré en bas (`data-admin-public-site`).
