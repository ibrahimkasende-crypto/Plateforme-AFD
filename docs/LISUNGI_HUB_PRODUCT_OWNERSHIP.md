# Propriété produit — Lisungi Hub

## Clarification juridique / produit

| Entité | Nature | Propriétaire du code |
|--------|--------|----------------------|
| Lisungi Hub | Éditeur / startup | Oui |
| LISUNGI | Produit SaaS | Lisungi Hub |
| AFD ASBL | Organisation cliente | Non — utilisatrice |

## Ce que l’AFD n’est pas

- Pas l’éditeur technique de LISUNGI
- Pas le propriétaire de la marque produit LISUNGI
- Pas une instance « Plateforme-AFD » au sens produit (legacy naming)

## Ce que Lisungi Hub n’est pas

- Pas une ONG
- Pas l’organisation affichée sur le site public `afd-rdc.org`

## Accès support

Tout accès support Lisungi Hub à une organisation cliente doit être :

1. Autorisé
2. Temporaire lorsque possible
3. Limité au périmètre nécessaire
4. Journalisé
5. Révocable

Les rôles `platform_*` et `support_agent` ne donnent pas d’accès silencieux aux données sensibles des ONG.
