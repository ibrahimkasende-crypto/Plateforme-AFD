# Guidelines de marque LISUNGI / AFD

## Règles

1. Site public = identité AFD exclusive (logo, favicon, textes).
2. Admin = LISUNGI comme produit, AFD comme organisation active.
3. Lisungi Hub = éditeur uniquement (jamais présenté comme ONG).
4. Ne pas inventer ni déformer les logos officiels.
5. Dans les rapports institutionnels : logo AFD ≥ logo produit/éditeur.
6. Centraliser les libellés dans `product-brand.ts` et `organization-brand.ts`.

## Hiérarchie visuelle admin

1. **Produit** : logo LISUNGI + nom + tagline
2. **Organisation** : logo AFD + nom + « Organisation active »
3. **Éditeur** : « Un produit Lisungi Hub » (discret)
