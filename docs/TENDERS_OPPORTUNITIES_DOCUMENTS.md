# Appels d’offres, opportunités et documents

- AO : `/admin/publications/appels-offres` — documents dans Storage
- Opportunités : bucket `opportunites` (public) ; candidatures dans `candidatures-privees` (privé, URL signées)
- Documents / rapports : publication uniquement des contenus `publie`

Modules Studio reliés aux CRUD existants (`/admin/opportunites`, `/admin/documents`, `/admin/rapports`).
