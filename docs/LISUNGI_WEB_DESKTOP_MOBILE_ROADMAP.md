# Roadmap Web / Desktop / Mobile

## Phase actuelle — Web (AFD)

- Co-branding LISUNGI + organisation AFD
- Fondations multi-organisations
- Abonnement pilote non bloquant

## Phase suivante — Multi-tenant Web

- Sélecteur d’organisation (memberships > 1)
- RLS stricte sur toutes les tables métier
- Portail support journalisé

## Desktop

- Client hors-ligne pour équipes terrain / bureaux
- Sync différentielle Supabase
- Même auth & mêmes rôles

## Mobile

- Agents terrain (`agent_terrain`)
- Saisie activités / enquêtes
- Photos + files Storage
- Sync opportuniste

## Non-objectifs immédiats

- Refonte du site public AFD
- Facturation automatisée (montants officiels)
- Migration destructive des données
