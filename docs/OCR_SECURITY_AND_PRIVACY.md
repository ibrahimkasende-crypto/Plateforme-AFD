# Sécurité et confidentialité

- Pas de `NEXT_PUBLIC_` sur clés OCR / service_role  
- Bucket privé, URLs signées courtes  
- Classification sensibilité (interne → strictement_confidentiel)  
- MIME / extension / taille / hash / doublons  
- Hook antivirus prévu (non bloquant)  
- RLS + permissions serveur + Storage  
- Documents OCR jamais publics par défaut
