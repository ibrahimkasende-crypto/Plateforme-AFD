# Intégrité et authenticité

Statuts d’intégrité (jamais « document authentique » sur OCR seul) :

- intégrité cryptographique vérifiée  
- signature numérique vérifiée (certificat non de confiance)  
- signature invalide / modifié après signature  
- non signé  
- vérification indisponible  
- document non vérifié / nécessitant vérification / suspect / rejeté  

Signature manuscrite ou cachet OCR ≠ preuve cryptographique.
