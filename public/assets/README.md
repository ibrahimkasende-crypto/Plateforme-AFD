# Assets médias — Plateforme-AFD

Tous les fichiers servis publiquement sont dans `public/assets/`.  
URL publique : `/assets/...`

## Emplacement absolu

`D:\Plateforme-AFD\AFD\public\assets`

## Structure

| Dossier | Usage |
|---------|--------|
| `brand/` | Logo officiel |
| `home/` | Visuels page d’accueil (hero, présentation) |
| `programmes/` | Images des programmes |
| `projets/` | Images des projets terrain |
| `impact/` | Histoires d’impact, portraits |
| `actualites/` | Couvertures d’actualités |
| `partenaires/` | Logos partenaires |
| `mediatheque/` | Galerie / documents visuels |
| `newsletter/` | Visuels popup / bandeau newsletter |
| `equipe/` | Photos équipe / gouvernance |
| `zones/` | Cartes et visuels géographiques |
| `placeholders/` | Placeholders provisoires |
| `og/` | Images Open Graph / partage social |
